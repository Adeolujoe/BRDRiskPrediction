This repository contains the synthetic dataset, data-generation workflow, and machine-learning analysis code developed for a simulation-based framework for predicting bovine respiratory disease risk in feedlot cattle. The framework integrates 23 literature-informed animal, environmental, health, and management factors; benchmarks logistic regression, random forest, support vector classifier, k-nearest neighbors, and XGBoost; and evaluates discrimination, calibration, threshold performance, uncertainty, permutation importance, and SHAP-based model explanations. The materials support transparent reproduction and future empirical validation of the framework using real-world precision-livestock and veterinary health data. Results represent methodological feasibility within an engineered simulation environment and should not be interpreted as field-validated clinical performance
